# Release recheck: 2026-10-17

The public dataset at HF revision [`789111aff84058db4bb1d2a2441e8fbd8ea469bc`](https://huggingface.co/datasets/Alexzhao0605gt/EMBER-Bench/tree/789111aff84058db4bb1d2a2441e8fbd8ea469bc) was downloaded anonymously into a new directory and compared with the actual `v20260922_final` evaluation inputs. No dataset content was changed during this check.

## Dataset identity and completeness

* All 699 MP4s and 699 JPEGs are byte-identical to their local evaluation counterparts (SHA-256 and byte counts). The canonical media index, local catalog, HF catalog, and remote object inventory agree. Missing, extra, truncated, duration-mismatched, and resolution-mismatched videos: **zero**.
* FFprobe independently inspected both copies of every video. Dimensions, duration, frame rate, frame count, time base, start time, and rotation match exactly.
* Every downloaded video was fully decoded: **425,621 frames**, zero errors, zero audio streams. All have landscape geometry, 5 Hz frame rate, and zero display rotation. Every downloaded JPEG was decoded and verified against its local counterpart.
* All seven authoritative question-bank hashes, 699 answers/decision frames, P options, and 151 P/C pairings passed.

See the [699-row comparison](data/media_equivalence_20261017.csv) and [machine-readable audit](data/recheck_20261017.json).

## Evaluator and terminal

All **699 real-media questions** passed through the Chat Completions frame adapter to a loopback-only mock API at 1 Hz / 128 output tokens. The 699 requests transmitted 85,828 images. Predictions, pooled accuracy, all seven cells, counts, and artifact hashes were independently checked. Resume and summarize each made **zero additional requests**. These arbitrary mock scores are not model results.

Seven independently downloaded questions cover every scenario/type cell. An intentionally malformed answer was retained as incorrect; an intentional HTTP 401 returned exit code 2 with an incomplete summary and then resumed after the local authorization simulation was corrected. Candidate export validated the resulting artifacts.

Terminal tables match `summary.json`, show counts and percentages, distinguish missing splits with `N/A`, flag incomplete/mock runs, and print result paths. Two reporting defects were fixed: exhausted unanswered questions now display as done on resume, and summarizing a nonexistent run fails visibly. Downloads now show verified-file progress.

**35 regression tests and 10 subtests passed.** The built wheel was unpacked outside the source checkout and exercised through all four local adapters, confirming packaged configuration and fixture media. The repository CI verifies Windows, Linux, and macOS; see the checks on the commit containing this report.

## Scope and retained limitations

This is release engineering validation, not a paid provider evaluation or exact reproduction of the frozen paper table. The existing sampled upright-ego visual review remains applicable because the media are byte-identical. Four C videos retain vertical OPTION text; five have brief gold-label exposure that reduced sampling can miss.
