# Evaluation data preparation: 2026-10-17

The checked `v20260922_final` archive supplies 699 questions: L1-P 205, L2-P 113, L2-C 58, L3-P 128, L3-C 60, L4-P 102, L4-C 33. The public package contains 699 MP4s and 699 JPEGs totaling 5,017,144,232 bytes (4.67 GiB). Raw construction videos and unblurred backups remain outside the publication allowlist.

## Validation evidence

* 699/699 videos fully decoded; 425,621 frames; zero audio streams or decode failures.
* Every video has landscape dimensions, 5 Hz frame rate, and zero display rotation.
* All 699 current images fully decoded and checked for landscape dimensions and normal EXIF orientation.
* SHA-256 validation covers every evaluation media file; the source archive's 2,390 transport entries also passed after its metadata updates.
* All 699 videos received sampled visual inspection at 10%, 50%, and 90% for upright egocentric presentation. This does not certify every frame's semantics or face privacy.
* 75 L1/L2 histories and corresponding decision images required 90-degree counterclockwise rotation. Frame PTS arrays, frame counts, frame rate, and duration were preserved. The minimum per-frame PSNR against the lossless rotation reference was 40.93 dB after CRF 16 encoding. The other 624 video/image pairs retained their prior hashes. Originals were preserved locally using `_not_blur` names.
* Four rotated C videos retain rotated OPTION text, preserving the exact letters and exposure windows. Five previously documented brief gold-label exposures remain. See the [dataset card](../dataset_card/README.md).

The release catalog is built from canonical media paths, authoritative question banks, and matching canonical timelines. Legacy task-number mappings are not reused for objectives or action logs. All 151 C known next actions exactly match the correct option of their paired P question. Reference answers, P options, question IDs, and decision frames were checked against the original banks.

The data format was loaded locally with Hugging Face Datasets 5.1.0 as a standard VideoFolder `test` split with 699 rows and a Video feature. The code package was installed into a fresh Python 3.12 environment. **32 tests and 10 subtests passed**. An offline mock test passed through three protocols/four input adapters with 20 mock requests and zero additional requests on resume. Seven real-media examples (one per scenario/type cell) also passed through a loopback Chat Completions frame adapter, including the exact custom deployment name and output-budget forwarding. All seven answers parsed successfully; resuming issued zero requests. These arbitrary mock predictions are not benchmark accuracy. No paid model run or frozen paper-score reproduction is claimed.

A fresh anonymous download passed for all seven scenario/type cells (seven questions and fourteen media files). Each subset passed CLI schema/path/hash validation. Those downloaded media then passed through the loopback API, producing seven parseable responses and zero additional requests on resume. No paid API calls were made. The machine-readable [publication receipt](data/release_20261017.json) records the revision and checks.

For maintainers, `scripts/build_release.py --source CHECKED_ARCHIVE --out STAGING` builds the evaluation media and annotations. A complete release also needs the card/license, known limitations, and an `audit.json` with verified full-decode and visual-review status. `scripts/publish_dataset.py --folder STAGING --publish` checks the allowlist and local checksums, uploads privately, verifies all remote Git/LFS objects, and only then makes the dataset public. It requires prior `hf auth login` as the dataset owner; credentials never belong in Git.

The GitHub quick start and website link to the verified public release. The frozen paper leaderboard is unchanged; local mock predictions are never leaderboard entries.
